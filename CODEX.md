# BDB DEV Optimized Agent Skills for Codex CLI & ChatGPT Codex

This repository provides an optimized suite of **140+ agent skills**, Model Context Protocols (MCPs), and workflow engines designed for autonomous AI agents.

## 🚀 Native Codex CLI Installation

Add this plugin directly via the Codex CLI marketplace:

```bash
codex plugin marketplace add hybridlabor-api/bdb-dev-optimized-agent-skills
codex plugin add bdb-dev-optimized-agent-skills
```

Or install universally across all detected AI environments on your system:

```bash
npx @hybridlabor-api/bdb-dev-optimized-agent-skills@latest -y
```
